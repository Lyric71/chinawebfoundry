## A real bug, and it blocks two of the work order's own criteria

`GuideLayout.astro` styles `.table-wrapper` with `overflow-x: auto` at line 318
and sets `min-width: 400px` on mobile tables at line 326. The wrapper element
is created at lines 481 to 487 **by a client-side script**. Criterion 3
requires the table be verified server-rendered with JavaScript disabled, and
criterion 4 requires no sideways body scroll at 390px. With JavaScript off
there is no wrapper, so a 400px table in a 390px viewport overflows the body.

Latent on all 33 guides in four locales today. A 43-row six-column table makes
it visible. The fix is items 13 and 14 of the change list: a build-time rehype
plugin, and deletion of the five-line client script. **The publish step must
apply it**, or the page fails its own acceptance list.

## A tooling failure worth recording

Two Bash paths corrupted content and both were abandoned mid-run.

Heredocs through the Bash tool mangled the CJK strings and the curly quotes,
so the English file would not write at all. Then an inline `python -c` script
meant to insert French non-breaking spaces wrote a literal `U+0001` in place
of every regex backreference, which silently deleted the colons and semicolons
from the first FR draft, frontmatter included.

That FR file was discarded and rewritten from scratch. Nothing was published
from the corrupted state. Every locale file is now written with the Write
tool, and the French typography step runs through
`editorial/scripts/fr-typography.mjs`, committed with this piece: it inserts
the non-breaking space before `: ; ? !` and `%`, handles the guillemets,
skips the YAML frontmatter so `key: value` stays parseable, and leaves URLs
alone. This is the substitution `CLAUDE.md` asks to be logged rather than
stalled on.
