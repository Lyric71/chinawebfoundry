Eine Ausschreibung für eine Website in China braucht sechs Abschnitte, die in einem westlichen Briefing selten vorkommen: Gesellschaft und Registrierung, die Entscheidung über das Hosting, Technik und Eigentum, chinesische Inhalte, Sichtbarkeit in Suchmaschinen und KI-Assistenten sowie die Frage, wer nach dem Start die Schlüssel in der Hand hält. Fehlen sie, füllt jeder Anbieter die Lücken nach eigenem Gutdünken, und am Ende liegen Angebote für verschiedene Projekte auf dem Tisch.

Die Checkliste steht als reiner Text am Ende der Seite. Schicken Sie sie an jeden Anbieter auf Ihrer Auswahlliste, auch an uns. Alle hier zitierten Vorgaben der Hosting-Anbieter haben wir am 1. Oktober 2026 erneut an der Quelle geprüft.

| Abschnitt                       | Was das Briefing festlegen muss                         | Was ohne ihn schiefgeht                                |
| ------------------------------- | ------------------------------------------------------- | ------------------------------------------------------ |
| Gesellschaft und Registrierung  | Welche chinesische Gesellschaft registriert, und wann   | Die Website ist fertig und darf nicht online gehen     |
| Hosting                         | Server in Festlandchina oder eine Begründung dagegen    | Zwei Anbieter kalkulieren zwei verschiedene Projekte   |
| Technik und Eigentum            | Plattform, Konten und Ausstiegsbedingungen              | Dem Anbieter gehört der Server, den Sie bezahlen       |
| Chinesische Inhalte             | Wer die Texte freigibt; wohin Formulardaten gehen       | Daten verlassen China ohne Einwilligung                |
| Suche und KI-Assistenten        | Baidu-Arbeit über die Verifizierung hinaus              | Eine eingereichte Sitemap, sonst nichts                |
| Wartung und Zugänge             | Wie Updates einen Server in Festlandchina erreichen     | Updates bleiben nach dem Start unbemerkt aus           |

## Was ein übliches Briefing auslässt

In Festlandchina kann eine fertige Website wochenlang dunkel bleiben, denn der Server liefert Ihre Domain erst aus, wenn eine behördliche Registrierung abgeschlossen ist.

> Eine Domain, die auf einen Server in Festlandchina auflöst, muss ihre Registrierung abschließen, bevor der Zugang zur Website freigeschaltet werden kann.
> Quelle: Hilfecenter von Alibaba Cloud (阿里云), 4. September 2026.
> https://help.aliyun.com/zh/dws/support/how-do-i-troubleshoot-the-failures-to-access-a-website-by-using-its-domain-name

Diese eine Regel stellt den Projektablauf auf den Kopf: Niemand kann einen Zeitplan zusagen, solange das Briefing die registrierende Gesellschaft nicht nennt. Ein westliches Briefing nimmt außerdem die Drittanbieter-Skripte der Website und den Lieblingshoster der Agentur ungeprüft hin, verbucht chinesische Texte als Übersetzung und überlässt Baidu einem Plugin.

## Abschnitt für Abschnitt: was eine Ausschreibung für eine China-Website abdecken muss

Sechs Abschnitte, in der Reihenfolge, in der ein Anbieter sie braucht.

### Gesellschaft und Registrierung

Die ICP-Registrierung (ICP备案) reicht eine in Festlandchina eingetragene Gesellschaft ein. Nennen Sie diese Gesellschaft, und sagen Sie, ob es sie schon gibt.

> Internationale Konten von Alibaba Cloud (alibabacloud.com) unterstützen keine ICP-Registrierung. Antragsteller muss ein in Festlandchina eingetragenes Unternehmen oder eine in Festlandchina ansässige Person sein, mit einem Konto bei aliyun.com.
> Quelle: Hilfecenter von Alibaba Cloud (englische Fassung), 20. August 2026.
> https://help.aliyun.com/en/icp-filing/basic-icp-service/product-overview/icp-filing-application-for-enterprises-outside-the-chinese-mainland

Im Projektplan jedes Anbieters sollte die Registrierung als eigener Arbeitsschritt erscheinen, mit eigens eingeplanten Wochen.

> Die Vorprüfung durch Alibaba Cloud dauert 1 bis 2 Arbeitstage. Die Kommunikationsverwaltung der Provinz (省级通信管理局) braucht in der Regel 1 bis 20 Arbeitstage. Die Registrierung bei der öffentlichen Sicherheit (公安备案) ist innerhalb von 30 Tagen nach dem Start der Website fällig.
> Quelle: Hilfecenter von Alibaba Cloud (阿里云), 26. August 2026.
> https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview

Soll die Website kostenpflichtige Online-Dienste verkaufen, sagen Sie es: Dann kann zusätzlich eine ICP-Lizenz (ICP许可证) fällig werden, ein eigenes Verfahren, das deutlich länger dauert. Unser Leitfaden zur [ICP-Registrierung für ausländische Unternehmen](/de/ressourcen/china-web-leitfaden/icp-lizenz-auslaendische-unternehmen/) listet die Unterlagen auf.

### Die Entscheidung über das Hosting

Verlangen Sie einen Ursprungsserver in Festlandchina oder eine schriftliche Begründung für Hosting in Hongkong oder weiter entfernt, belegt mit Ladezeiten, gemessen aus einem Netz in Festlandchina. Ein Server in Festlandchina setzt eine Registrierung voraus, und zwar für genau diesen Server.

> Für eine Registrierung über Alibaba Cloud ist ein Server in Festlandchina mit einer Laufzeit von mindestens 3 Monaten erforderlich.
> Quelle: Hilfecenter von Alibaba Cloud (englische Fassung), 24. September 2026.
> https://help.aliyun.com/en/icp-filing/basic-icp-service/user-guide/icp-filing-server-access-information-check

Der Server wird also zuerst gekauft, auf den Namen der registrierenden Gesellschaft.

Lassen Sie sich das schriftlich geben.

### Technik und Eigentum

Nennen Sie die Plattform, die Ihnen vorschwebt, oder lassen Sie jeden Anbieter eine vorschlagen und begründen. WordPress und Astro laufen in Festlandchina beide ohne Weiteres. Welche passt, hängt davon ab, wer die Inhalte pflegt und an welche Systeme die Website angebunden werden muss.

Fällt die Wahl auf WordPress, fragen Sie, wer den Server betreibt, denn wir haben keine chinesische Cloud gefunden, die verwaltetes WordPress anbietet. Der Simple Application Server (轻量应用服务器) von Alibaba Cloud installiert es aus einem vorkonfigurierten Image auf einem Server, den Sie selbst verwalten, Lighthouse von Tencent Cloud (腾讯云) und FlexusL von Huawei Cloud (华为云) funktionieren genauso, und keiner davon spielt für Sie ein Plugin-Update ein oder stellt eine Sicherung wieder her. Updates und Sicherungen bleiben an jemandem hängen, und das Briefing sollte sagen, an wem.

Führen Sie jedes Konto auf, das für das Projekt angelegt wird (aliyun.com, Domain-Registrar, CMS-Administration, Webanalyse), und verlangen Sie, dass alle auf den Namen des Kunden laufen.

### Chinesische Inhalte

Übersetzen und auf Chinesisch texten sind zwei verschiedene Handwerke. Sagen Sie, welche Sie wollen, und wer in Ihrem Haus den chinesischen Text freigibt (und wie lange das tatsächlich dauert).

Legen Sie dann fest, wohin Formulareingaben gehen. Ein Kontaktformular, das ein CRM außerhalb Chinas speist, zieht eine gesetzliche Pflicht nach sich.

> Wer personenbezogene Daten aus der Volksrepublik China heraus übermittelt, muss der betroffenen Person mitteilen, wer sie empfängt, und ihre gesonderte Einwilligung einholen.
> Quelle: Cyberspace-Verwaltung Chinas (中央网络安全和信息化委员会办公室), Gesetz zum Schutz personenbezogener Informationen, Artikel 39, 20. August 2021.
> https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm

### Suche und KI-Sichtbarkeit

Yoast und Rank Math speichern beide einen Verifizierungscode für Baidu (百度).

> In den Einstellungen „Site connections“ von Yoast SEO wird der Verifizierungscode für die Baidu Webmaster Tools hinterlegt.
> Quelle: Yoast-Hilfecenter, aktualisiert am 29. April 2026.
> https://yoast.com/help/add-website-baidu-webmaster-tools/

Wir haben im August 2026 den Code beider Plugins gelesen: Dieses Tag war das Einzige, was eines der beiden speziell für Baidu ausgab. URL-Einreichung, Baidu Tongji (百度统计), strukturierte Daten im Baidu-Format und robots.txt-Regeln für Baiduspider sind Handarbeit. Jemand muss dafür zuständig sein, und die Antwort sollte sagen, wer.

Dann kommt das Rendering. Baidu hat seinen rendernden Crawler, Baiduspider-render/2.0, im März 2017 angekündigt und veröffentlicht nichts darüber, wie viel er rendert. Serverseitig erzeugtes HTML ist deshalb die risikoärmere Wahl. Fragen Sie außerdem, welche chinesischen KI-Assistenten der Anbieter daraufhin prüft, ob Ihr Markenname in den Antworten auftaucht. DeepSeek, Doubao (豆包), Kimi, Qwen (通义千问) und Yuanbao (元宝) sind die Namen, die fallen sollten.

### Wartung und wer die Schlüssel hält

Wie gelangen Core- und Plugin-Updates auf einen Server in Festlandchina?

> Mitarbeiter von WordPress.org schrieben, dass mehrere chinesische Netzquellen bei bestimmten Diensten wegen Missbrauchs gedrosselt werden und dass es keine Ausnahmeliste geben werde.
> Quelle: WordPress.org Meta Trac, Ticket Nr. 5106, 21. März 2020.
> https://web.archive.org/web/20260116133057/https://meta.trac.wordpress.org/ticket/5106

Welche externen Skripte bleiben auf der Seite? Ein Theme, das jQuery von ajax.googleapis.com lädt, legt die Seite lahm, solange es wartet.

> Bei Tests von einer Alibaba-Cloud-Instanz (阿里云) in cn-zhangjiakou am 28. August 2026 lieferte Google Hosted Libraries in keinem der 3 Durchläufe ein erstes Byte, jeder wurde nach 60 Sekunden abgebrochen.
> Quelle: 21YunBox, Google Hosted Libraries in China, 30. August 2026.
> https://www.21cloudbox.com/support/google-hosted-libraries.html

Bleibt der Ausstieg. Ein Anbieter, der den Serverzugang und die Domain hält, kann jeden Anbieterwechsel verschleppen. Halten Sie fest, was am letzten Vertragstag an Sie zurückgeht.

## Die Fragen, die Anbieter schriftlich beantworten sollten

Unser Leitfaden zur [Auswahl einer Webagentur in China](/de/ressourcen/china-web-leitfaden/webagentur-china-auswaehlen/) enthält acht Fragen für das erste Gespräch. Die folgenden sieben gehören in die schriftliche Antwort, denn was darauf geantwortet wird, landet im Vertrag.

1. Auf wessen Namen läuft die ICP-Registrierung, und welches aliyun.com-Konto hält den Server?
2. Wie viele Wochen sieht Ihr Plan für die Registrierung vor, und was läuft parallel?
3. Welche Drittanbieter-Hosts ruft die fertige Website noch auf? Bitte mit Namen.
4. Welche Ladezeit sagen Sie zu, gemessen aus welchem Netz in Festlandchina, an welchem Datum?
5. Wie gelangen Updates auf den Server, und wer spielt sie ein?
6. Wohin gehen Formulareingaben, und mit welcher Einwilligung?
7. Erhalten wir bei Vertragsende die Dateien und die Datenbank mit vollen Administratorzugängen?

## Warnsignale in den Antworten

| Antwort                                               | Was sie Ihnen sagt                                              |
| ----------------------------------------------------- | --------------------------------------------------------------- |
| „Wir hosten das auf unserem Konto“                    | Der Server, an dem die Registrierung hängt, gehört nicht Ihnen  |
| Ein Starttermin ohne Wochen für die Registrierung     | Der Plan wurde für einen westlichen Start geschrieben           |
| Eine Ladezeit ohne Netz und Datum                     | Sie können nicht erkennen, wo und ob überhaupt gemessen wurde   |
| „Unser SEO-Plugin deckt Baidu ab“                     | Das Plugin erledigt die Verifizierung, und dabei bleibt es      |
| Keine ICP-Nummer im Footer ihrer eigenen Website      | Fragen Sie nach: Die eigene registrierte Website ist der einfachste Beleg |
| Schweigen dazu, wohin Formulardaten gehen             | Personenbezogene Daten verlassen China womöglich ohne Einwilligung |

Der Blick in den Footer dauert zehn Sekunden, und diese Prüfung muss jede registrierte Website bestehen.

> Nach der Registrierung muss eine Website ihre ICP-Registriernummer unten auf der Seite anzeigen, verlinkt auf beian.miit.gov.cn. Fehlt sie, droht durch die Kommunikationsverwaltung der Provinz ein Bußgeld von 5.000 bis 10.000 Yuan.
> Quelle: Hilfecenter von Alibaba Cloud (阿里云), 12. August 2026.
> https://help.aliyun.com/zh/icp-filing/basic-icp-service/the-icp-record-post-processing-1

## Die Checkliste

Übernehmen Sie sie unverändert, und passen Sie dann die Formulierungen an Ihr Haus an.

- Registrierende Gesellschaft: das in Festlandchina eingetragene Unternehmen, das die ICP-Registrierung halten wird, und ob es heute schon existiert.
- Art der Registrierung: ICP-Registrierung, oder ICP-Lizenz, wenn die Website kostenpflichtige Online-Dienste verkauft.
- Zeitplan der Registrierung: die eingeplanten Wochen, dazu die Registrierung bei der öffentlichen Sicherheit innerhalb von 30 Tagen nach dem Start.
- Server: Anbieter und Region in Festlandchina, Laufzeit von mindestens 3 Monaten, gekauft auf den Namen der registrierenden Gesellschaft.
- Konten: aliyun.com, Domain-Registrar, CMS-Administration und Webanalyse, alle auf unseren Namen.
- Plattform: benannt und begründet mit Blick auf unsere Art der Inhaltspflege.
- Drittanbieter-Hosts: alles, was die Website heute aufruft, und was die fertige Website noch aufrufen wird.
- Ladezeit: ein Zielwert, das Netz in Festlandchina, aus dem gemessen wird, und das Datum.
- Chinesische Texte: geschrieben oder übersetzt, von wem, und wer sie freigibt.
- Formulare: wo die Eingaben gespeichert werden, und der Wortlaut der Einwilligung.
- Baidu: Verifizierung, URL-Einreichung, Baidu Tongji, Rendering.
- KI-Assistenten: welche chinesischen Assistenten beobachtet werden, und wie.
- Updates: wie Core- und Plugin-Updates einen Server in Festlandchina erreichen, und wer sie einspielt.
- Ausstieg: Dateien und Datenbank, übergeben mit Administratorzugängen.
- Budget: Position für Position kalkuliert, mit Registrierung, Hosting, chinesischen Texten und Baidu-Arbeit als eigenen Posten.
- Nachweis: eine laufende Website, die der Anbieter betreut, mit ICP-Nummer im Footer.

## Häufige Fragen

**Kann eine Ausschreibung an Anbieter in China und außerhalb Chinas gehen?**
Ja. Dieselbe Liste trennt die Anbieter, die selbst in Festlandchina registrieren und hosten, von denen, die Unteraufträge vergeben. Bitten Sie jeden Anbieter, die Punkte zu markieren, die er an einen Partner weitergibt, und diesen Partner zu nennen. Ein leeres Feld bei der registrierenden Gesellschaft oder beim Server sagt mehr als der Rest der Antwort.

**Brauchen wir eine chinesische Gesellschaft, bevor wir überhaupt jemanden briefen?**
Sie brauchen sie vor der Registrierung, und die liegt auf dem kritischen Pfad. Sprechen Sie Anbieter ruhig an, während die Gesellschaft gegründet wird, aber rechnen Sie mit keinem festen Starttermin, bevor die Gewerbelizenz vorliegt. Schreiben Sie ins Briefing, wie weit die Gründung ist und wann Sie die Lizenz erwarten, damit alle Anbieter vom selben Datum aus planen.

**Sollte die Ausschreibung WordPress vorschreiben?**
Nur wenn Ihr Team schon mit WordPress arbeitet und dabei bleiben will. Andernfalls lassen Sie jeden Anbieter eine Plattform vorschlagen und begründen, gemessen an Ihren redaktionellen Abläufen und Ihren Integrationen. [Eine Webagentur, die in China registriert und hostet](/de/webagentur-china/), sollte für beide Wege argumentieren können.

**Was sollte die Ausschreibung zum Budget sagen?**
Nennen Sie eine Spanne, wenn Sie eine haben. In jedem Fall verlangen Sie einen Preis pro Zeile der Checkliste. Angebote für China unterscheiden sich vor allem darin, was sie weglassen: Unterstützung bei der Registrierung, der Server in Festlandchina, die chinesischen Texte und die Baidu-Arbeit sind die Posten, die fehlen oder im Kleingedruckten als Aufgabe des Kunden wieder auftauchen.

**Wie viel Zeit sollten Anbieter für ihre Antwort bekommen?**
Zwei bis drei Wochen für eine fundierte Antwort mit Projektplan. Verlangen Sie einen datierten Ablauf, in dem die Registrierung eine eigene Zeile hat und der Serverkauf davor steht. Geht die Website laut Plan online, bevor die Registrierung abgeschlossen ist, schicken Sie den Plan zurück.
